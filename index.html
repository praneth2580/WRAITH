wraithWeb automation that behaves like a person

Scraping and browser automation for Node.js with human-like input, typed extraction, polite networking and optional AI. All in your own process, with no server and no hosted service.

🖱️

Human behaviour, one option away

Curved mouse paths with Fitts's-law timing and overshoot, typing with corrected typos, wheel scrolling and reading pauses. Pick a preset or tune any setting.

⚡

Browser or plain HTTP

A real browser for JavaScript-heavy sites, or a fast HTTP fetch for pages that don't need it. Both share one extraction API.

🧩

Typed extraction

Describe your data with CSS selectors and get typed results back, inferred from the schema itself.

⏳

Waits that understand the page

Clicks wait until a button is enabled and uncovered. waitForSettled() waits for requests, spinners and skeletons to finish.

🎭

Robust to generated class names

Find elements by role, label or text, read values next to their labels, or take the JSON the site loads from its own API.

🤝

Polite by default

A per-host rate limit, retries with backoff, and optional robots.txt checks including Crawl-delay.

🍪

Banners, pages and people

Reject or accept cookie banners automatically, page through Next, Load more and infinite scroll, and hand CAPTCHAs to a person.

🤖

Optional AI

Extract into a zod schema, ask questions, or give plain-language instructions. Ollama, Claude, OpenAI or any compatible server.

See it work ​

In a browser, like a person. The mouse travels a curved path to each element, keys are typed one at a time, and every action waits until its target is ready.

ts
import { createWraith } from 'wraithjs';

const wraith = createWraith({ human: 'natural' });
try {
  const page = await wraith.open('https://quotes.toscrape.com/login');
  await page.type({ label: 'Username' }, 'me');
  await page.type({ label: 'Password' }, 'secret', { typos: false });
  await page.click({ role: 'button', name: 'Login' });
  console.log(await page.text('.header-box'));
} finally {
  await wraith.close();
}

Without a browser, much faster. Download the HTML and extract typed data with selectors. The result type comes from the schema.

ts
import { createWraith } from 'wraithjs';

const wraith = createWraith();
const page = await wraith.fetch('https://books.toscrape.com/');

const { books } = page.extract({
  books: {
    selector: 'article.product_pod',
    list: true,
    fields: {
      title: 'h3 a@title',
      price: { selector: '.price_color', transform: (v) => Number(v.slice(1)) },
      link: 'h3 a@href', // made absolute for you
    },
  },
});
// books: { title: string | null; price: number | null; link: string | null }[]

Built for real sites ​

  • Dynamic pages: wait for them to settle, capture their JSON API, read embedded structured data.
  • Listings: Next buttons, Load more and infinite scroll, or crawl a whole site breadth-first.
  • Interruptions: cookie banners, and CAPTCHAs and one-time codes handed to a person.
  • Hard cases: AI extraction and plain-language actions with a local model or an API key.

Built on solid libraries ​

wraith doesn't reinvent what already works: Playwright drives the browser, cheerio parses HTML, zod validates AI output, p-queue and p-retry handle rate limits and retries, robots-parser reads robots.txt, node-html-markdown produces Markdown, and DuckDuckGo's autoconsent answers consent banners.
