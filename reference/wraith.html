Wraith ​

The object createWraith() returns. It holds one browser and one browser context (launched on first use), the per-host rate limiter and the AI client.

Pages ​

open() ​

ts
open(url: string, options?: GotoOptions & NewPageOptions): Promise<WraithPage>

Opens a new tab and navigates to url. Options: waitUntil ('load' default, 'domcontentloaded', 'networkidle', 'commit'), timeout, human to override the human behaviour for this tab, and instance to choose the instance. If the navigation fails, the tab is closed and the error thrown.

newPage() ​

ts
newPage(options?: { human?: HumanOption; instance?: number }): Promise<WraithPage>

Opens a blank tab in the instance with the fewest open pages, or in instance (from 0). Launches the browser if it isn't running. Throws WraithError for an instance number out of range.

fetch() ​

ts
fetch(url: string, options?: FetchOptions): Promise<StaticPage>

interface FetchOptions {
  method?: string;                    // default 'GET'
  headers?: Record<string, string>;
  body?: string;
  timeout?: number;                   // default network.timeout
}

Downloads a page without a browser and parses it. Redirects are followed. Goes through the same robots.txt check, rate limit and retries as browser pages. Throws HttpError if the status is still 408/425/429/5xx after retries; other statuses return a StaticPage with ok: false.

paginate() ​

ts
paginate(url: string, options: StaticPaginateOptions): AsyncGenerator<StaticPage>

interface StaticPaginateOptions {
  next: FieldSpec | ((page: StaticPage) => string | null | undefined);
  maxPages?: number;                  // default 10, counting the first
}

Follows Next links without a browser. next is a selector for the link (its href is followed), any field spec that yields a URL, or a function. Stops when next gives nothing, when it would revisit a URL, or at maxPages. Guide

Sessions and the browser ​

saveSession() ​

ts
saveSession(path: string, instance?: number): Promise<void>

Writes an instance's (default the first) cookies and localStorage to a JSON file. Start a later Wraith from it with context: { storageState: path }.

context() ​

ts
context(instance?: number): Promise<BrowserContext>

An instance's (default the first) Playwright BrowserContext, launching the browser if needed.

close() ​

ts
close(): Promise<void>

Closes every browser, instance and proxy connection. Static fetches keep working afterwards, and opening a browser page launches a new browser.
