createWraith options ​

ts
function createWraith(options?: WraithOptions): Wraith

Creates a Wraith. Nothing launches until the first browser page is opened, so creating one is cheap. Times are in milliseconds.

ts
import { createWraith } from 'wraithjs';

const wraith = createWraith({
  human: 'natural',
  headless: true,
  network: { respectRobotsTxt: true },
  waits: { afterAction: 'navigation' },
  consent: 'reject',
});

human ​

ts
type HumanOption =
  | boolean                               // true = 'natural', false = 'off'
  | 'off' | 'fast' | 'natural' | 'careful'
  | ({ preset?: HumanPreset } & DeepPartial<HumanBehavior>);

HumanBehavior has these settings. Ranges are [min, max] and sampled each time.

SettingType
enabledbooleanMaster switch. false is the same as 'off'
actionDelayRangePause before each click, type, select or press
mouse.enabledbooleanMove along a path before clicking
mouse.speednumber1 is an average person
mouse.overshootChancenumber0–1, for distant targets
mouse.jitternumberPixels of wobble on the path
mouse.hoverDelayRangePause between arriving and pressing
mouse.clickHoldRangeHow long the button stays down
typing.keyDelayRangeTime per key
typing.typoChancenumber0–1, per letter
typing.wordPauseRangeExtra pause after a space
scroll.stepRangePixels per wheel tick
scroll.stepDelayRangePause between ticks
reading.wordsPerMinuteRangePace for page.read()

Each preset's values are listed in the Human behaviour guide.
